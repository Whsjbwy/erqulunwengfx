# 阶段6A下一步决策

**决定：Need-Baseline-Evidence。6A完成后停止，等待研究者与ChatGPT审核；不自行开发原创规划器。**

目前值得保留一个窄研究问题，但不足以进入原创原型。原因是最邻近部分正文受限、成熟基线尚未原生运行、OMPL默认端点检查不等同于冻结连续证书，以及现代RDG/DIRT挑战的代码/许可尚未核验。没有将“未运行”填成失败，也没有把平台可行性写成实测成功。

## 下一次审核需要的具体证据

1. 合法获得Feng2024等最邻近方法正文，明确其曲率/净距/扩展策略与H1的数学差异。没有获取时保持访问限制，不能自行补写。
2. 原生Windows成熟SST/control RRT在独立环境构建运行；相同五状态、同初态、相同目标、正向传播、完整球扫掠和限幅验收，不能自写简化算法代替官方强基线。
3. 验证统一参考适配：原生控制可行和冻结LOS执行是两个指标；如果成熟控制轨迹也普遍不能由统一跟踪器执行，应先界定参考/控制契约，不能把这个接口差异归因于规划创新。
4. 核验DIRT/RDG作者代码与许可；若不可得，明确限制并重新审核强基线覆盖，不使用未授权代码或宣称SOTA完整。
5. 检查球外形保守性是否主导失败。若决定增加定向圆柱或动力学，必须新阶段、新协议并重建公平基线，不能在候选上单方面减小车体或放宽约束。

接下来更合理的是**补运动可行规划基线证据**，不是继续常规LOS扫参，也不是直接认定必须修真实AUV动力学。12例解析通过支持当前ODE/认证一致性；尚无辨识或海试证据足以在真实几何/动力学方向作唯一判断。

`Proceed-to-Prototype`仅在上述证据和文献差异均通过审核后可选；`Pivot`在等价先验、模型主导或成熟基线消除问题时可选。当前`Need-Baseline-Evidence`是科学结论，不把尚缺证据包装成创新成功。
