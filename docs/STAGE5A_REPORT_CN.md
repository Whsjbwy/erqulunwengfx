## 参考实现正确性与公平预算

RRT-Connect保留双树EXTEND/CONNECT、交换、线性最近邻和.05目标偏置，通过显式oracle接口适配有限尺寸。三个固定seed首轮与冻结旧代码路径在1e-12坐标容差内一致，扩展和插入数一致。主评估允许静态随机流重启，用满同一总预算，不把重启称RRT*。

RRT*实现选父、near、连续边检测、rewire及所有受影响后代代价更新；目标连接集合随重连重新比较。近邻r_n=min(η,γ(log n/n)^(1/3))，按原文定理38、工作空间体积上界及1.1系数设置γ。Informed在首解前普通采样，之后使用原始树解长度定义的三维旋转长椭球；SVD正规旋转、球体积均匀抽样、越界/障碍拒绝、退化方向和近最短情况均测试。不加pruning或自适应创新。

文献及逐项实现对照见[算法审计](STAGE5A_ALGORITHM_AUDIT_CN.md)。这是独立自编参考，不复制第三方源码；线性最近邻、目标偏置、精确点目标连接、停止条件及有限预算均明确披露，不能把单元测试当渐近最优性的实验证明。

正式每次30秒含搜索、独立完整路径认证和同一可中断贪心shortcut。原始长度改善候选才触发共同后处理；原始与最终最佳输出分列，后处理超时保留此前认证路径。1/5/10/30秒只使用当时已认证的解，不倒填，未获解长度缺失。RRT*持续维护单树，RRT-Connect静态重启；内层每次最多100000节点/1000000迭代，次数和工作量单列。

首次路径时间在完整独立认证后记录；几何最短是预算内最短认证解，不是全局最优证明。跟踪在规划后执行并另计墙钟，不能免费倒填到规划Anytime。旧4A的不同测量/后处理制度不与5A时间表直接混排。

## 有限尺寸、海床与运动学假设

所有新地图单位米、z向上、体素spacing=.5米。车辆为假设的长度2米、直径.4米圆柱，以方向无关球包络R=sqrt(1+.04)≈1.0198米保守包含；三种规划尺度为point0、bodyR、marginR+.25米。没有已确认型号，不能将这些值当真实车辆规格。

碰撞核连续求线段到闭体素盒的最小欧氏距离，障碍面/棱/角接触拒绝，完整包络须处于闭地图域。AABB只作宽相，不把盒膨胀或中心距离场插值当真值。体素平面将距离平方分为二次区间，逐段求驻点/端点；独立凸区间参考、随机小图、接触及spacing测试交叉验证。

近海底高度h是向上栅格化的分片常数高斯地形，整个包络受h与h+6米作业带约束。虚拟顶界是任务限制，与物理海床分别报原因；不能走到顶部绕过全部地形。每种尺度重新验证可达见证。孔径不足证书仅证明所选球包络不可达，不证明真实细长AUV在姿态空间无解。

运动学为p_dot=v(cosθcosψ,cosθsinψ,sinθ)，无洋流；速度固定1米/秒、允许速度范围.5—1.5米/秒，航向/俯仰速率上限10/5度每秒，|θ|≤20度，步长.1秒。参数全部是仿真假设，无加速度、滚转、水动力、反向或悬停能力。固定前视3米几何跟踪，初始航向对准地图起终点方向、初始俯仰0，各方法一致；终点只要求位置误差≤.75米，没有终端姿态约束。

位置用分段常值输入精确积分。每步曲线到弦的偏差由v sqrt(r²+q²)dt²/8包络，再扩大扫掠球检查全过程；图中每1秒姿态仅用于显示。最小间隙是3米截断、扣弦误差的保守下界。控制限幅本身使违例通常为0，必须同时报告饱和、跟踪误差、连续安全及到达；尖角没有被赋有限曲率。

点路径也必须先通过同一名义机体复核，才允许进入执行试验。几何拒绝不是控制器已执行失败。margin模式要求轨迹保留.25米余量；仅到达但丢失余量记失败，另列取消额外余量后的执行结果。原始与选中路径分别跟踪，同坐标只存/算一次；二者可能来自不同incumbent，不作纯shortcut因果消融。

## 主要失败机制

270次正式任务按最终选中输出/未获解完整分账：

| 分类 | 次数 | 解释 |
| --- | ---: | --- |
| 点路径不能通过名义机体 | 90 | 执行前几何拒绝 |
| 物理扫掠认证拒绝 | 83 | 几何包络路径有效，但固定跟踪偏离后不能连续认证；不自动声称已证实内部穿透 |
| 到达但规定余量不足 | 29 | 不是严格margin执行成功 |
| 跟踪偏差超限 | 12 | 超过预设3米 |
| 任务带扫掠拒绝 | 2 | 虚拟离底顶界，不能当物理岩石碰撞 |
| 无几何路径 | 23 | 15个已证明包络负例、8个已知几何可达的30秒预算失败 |
| 严格执行成功 | 31 | 不混合成跨尺度算法总体成功率 |

8个可达预算失败均在窄开口：N2/body三方法各2次，N1/margin两个star各seed4一次。N2/body失败seed为RRT-Connect2/3、两个star3/4。严格见证存在，不能写成算法或真实AUV无解。全部450完成记录另有2个功能阶段3秒预算失败，程序异常0、自动外部守护0；独立的1次人工中止已在修正记录披露。

普通障碍的60个body/margin任务均获几何解但未执行成功，48次物理扫掠拒绝、12次误差超限，失败模拟时间中位6.3秒。选中路线初始航向差约2.78°—51.40°，后续尖角、贴障碍绕行与固定前视/角速限制共同作用；没有做控制器或初始姿态消融，不能把全部失败唯一归因于初始航向，或证明不存在其他可执行轨迹。

所有实际积分运行的速度、角速度和俯仰违例均0，但大量输入饱和及执行失败表明限幅通过不等于可执行。几何规划器没有控制转弯可达、姿态连续性或跟踪误差管，单纯追求更短路径不是执行质量目标。

安全余量并非毫无作用。在body与margin均几何可达的共同5图/各25任务上，取消额外余量要求、只按名义机体及任务带验收时，执行次数随规划缓冲由body到margin分别为8→13、5→14、0→14；但严格保留.25米余量时只有7、5、0。它改善了部分名义机体保护，却不足以保证该控制器全程保留规定缓冲。这个小样本尺度干预不等于真实车辆参数标定。

原始最佳路径执行成功次数为body的1/6/3、margin的0/4/1；选中输出则11/7/1和7/5/0。共同后处理在部分任务有益，不能笼统称它必然改善或破坏执行；原始最佳和选中可能来自不同incumbent，这不是纯同源前后处理消融。完整路径需求及执行证据随CSV保留。

## 五个问题的回答与后续审核

1. **几何优劣部分保持。** RRT-Connect仍是快速且覆盖较好的工程主基线；star类在共同有效任务上获得约1%—3%的地图等权短路径收益，但没有全面速度或执行优势。
2. **尺寸和近底约束的首要影响是模型可行性及路径—执行衔接。** 点模型选中路径全部不能直接用于名义机体；N2/margin孔径不足是包络模型负例。已考虑尺寸后的主要失效仍是转向/跟踪偏离和安全余量消耗，近底还存在虚拟顶界违反。
3. **执行失败在本模型中很普遍。** body中三方法只有11/7/1次成功，margin只有7/5/0；结论针对给定球包络、固定1米/秒和预设跟踪器，不推广为真实AUV或算法总体不可能执行。
4. **保留RRT-Connect为几何主基线，RRT*与Informed为优化参考。** 本数据中RRT-Connect执行也更好，但绝对成功率仍不足以宣称已建立可靠执行策略；不因Informed更短就将其直接晋升执行主线。
5. **下一步先审核运动学及规划—跟踪一致性，暂不优先加洋流。** 先确认车型/包络保守性、初始姿态、限幅/前视参数和转弯可达的评估，再决定是否引入已有约束steering/轨迹策略作基线。此为研究建议，5A未实现这些机制，也不自动进入5B。
