# 阶段5A-E：执行评测校准与独立验证

**结论：Inconclusive，暂不批准原创规划算法方向。** 360个新地图规划任务和1224个实际执行条件已完成，完整核查通过；独立LOS的有限终点适配存在明确边界，控制/处理效果又随地图和规划器改变。下一步应先完善并验收标准跟踪器的有限终点衔接，再决定规划创新；同时补足车辆几何与运动参数的真实依据。本阶段到此停止，不实施下一阶段。

## E0：基线、路径进度和连续安全验收

450个历史记录与公开CSV的33,670个字段一致。按先验规则选择每张旧图“最早失败＋最早成功，无成功则最晚失败”共12条路径，重新调用旧跟踪与原始历史轨迹指标逐项比较，通过后才继续E1。新解析验收包含直线、R=30米圆弧、受控上浮，以及初始航向不一致、急角障碍、过窄孔和高度任务带负例；3个控制条件×7场景和1个独立积分/坐标验收共22条记录。它们是正确性验收，不是新地图科研样本。

旧`Route.projection()`搜索全路径最近线段，旧控制将进度保持为历史最大值。这种约定在回折路径上可能不连续；合成例中位置移动0.002米，最近映射弧长跳16.2米。实际旧1099条件中发现177个大于0.5米的步间映射变化标记，全部公开。该阈值仅为描述性检索规则，不能把标记数当软件缺陷数，也没有据此改动旧控制器。

旧910个失败条件逐一补充首次失败的连续时间区间、最近段、参考与控制进度、前视目标、姿态/饱和、局部参考间隙和实际扫掠拒绝原因。局部安全间隙按1米弧长邻域逐顶点拆分计算；受3米截断影响的保守下界只作预警，误差/间隙比不能替代完整扫掠认证。统一3米横向误差阈值不代表在窄孔或靠障碍路径附近存在3米安全管。

安全仍使用长2米、直径0.4米假设圆柱的姿态无关外接球，名义半径约1.0198米，margin另加0.25米。位置采用分段常角速精确积分，每0.1秒以弦偏差界扩大扫掠球认证整段曲线；闭障碍、工作空间和近底任务顶界分别处理。几何见证只认证该球模型的位置空间可达性，不认证姿态运动可达性。

冻结跟踪流程先计算候选末状态并记录，再检查拒绝条件。因此失败图中的叉和CSV末位置可能是被拒绝区间的候选终点，不能称为车辆已被批准执行到该位置。拒绝扩大扫掠弦本身也不必然证明实际模型曲线交叠；最终首次失败区间另以独立点到盒距离和Lipschitz下界区分球模型交叠、可认证安全和未决接触带。即使证实球模型交叠，仍不是细长实体AUV碰撞证据。

## E1：成熟三维LOS对照和一次开发选择

引导来源为Breivik与Fossen (2005)，[作者公开原文](https://www.fossen.biz/publications/2005%20Breivik%20and%20Fossen%20CDC.pdf)，DOI 10.1109/CDC.2005.1582226。路径坐标误差(s,e,h)、横向/垂向LOS角、旋转映射和虚拟点进度对应原文式(37)(38)(46)(54)(56)(57)。实现转为z向上坐标，两方向前视均为Δ，虚拟进度按期望方向的切向分量加沿程反馈推进，γ=1，采用0.1秒Euler并夹到有限路径范围。它不是原全局最近点前视算法改名。

LOS与旧控制共用角度比例内环、精确运动学积分、速度1米/秒、航向角速10度/秒、俯仰角速5度/秒、俯仰角±20度、终点容差0.75米、初始航向指向任务终点且俯仰0，以及同一仿真时长和连续安全规则。折线切向不连续、有限路径进度夹取、实际限速内环均是明确适配，不能继承原文理想光滑路径、瞬时跟随条件下的稳定性结论。

固定12条先验样本先运行3个控制条件，随后完整157条selected路径按“地图等权严格完成→地图等权名义完成→地图等权全路径RMS误差→较小Δ”一次选择。所有候选结果均保留，没有直接把旧1.5米前视设为默认，也没有用新地图结果选参。

水平参考初版CSV将共享圆弧元数据展开到每行，容易把圆弧长度误读为raw/shortcut长度。本阶段保留原始压缩记录，派生导出将各自指标标为`input_*`、共享参考标为`curve_reference_*`：raw=70米，shortcut=49.4975米，fillet约67.5408米；尖角曲率不填0，记为未定义。原始轨迹和执行成功标签没有改动。

## 执行失败机制：已经证实与尚未解决

首次230个名义球扫掠拒绝区间中，独立点到盒距离在226个发现实际模型球交叠样本，4个停在约0.5毫米Lipschitz接触未决带，不能把后4个写成已证实交叠。108个余量失守在所要求的加大包络下均发现任务约束交叠，其中107个涉及物理障碍，1个仅额外球余量触及虚拟顶界。这仍不等同细长实体AUV碰撞。

**终点适配是新发现的明确混杂机制。** LOS的72个误差超限条件中54个在最近路径进度和控制进度都到达路径末端后失败，集中于O1的14个和O3的40个；旧控制对应为15个误差失败中的8个。实际数据见`terminal_diagnostics.csv`。事后解析边界核查将直线路径末端设为(10,0,0)、车辆置于(11,0,0)、虚拟进度夹到10，实际调用冻结LOS得到前向目标(12,0,0)，期望方向与指向终点的方向内积−1。它证明这个有限路径适配缺少终点吸引，不能证明54个案例若修复就必定成功，也不改变任何已运行结果。

因此，E1开放直线/缓曲线验收通过只说明已测正例可到达；标准LOS引导数学定义不等于有限终点控制完整合格。本阶段保留缺口、增加回归检查并停止在不确定，不在看过独立结果后偷偷增加终点切换或重新调参，也不把理想路径跟随稳定性证明外推到该适配。

小间隙与运动需求也有实际证据：425个失败中413个失败处参考邻域间隙下界小于统一3米误差阈值，说明该阈值不能充当安全管；raw两控制共232个失败中151个输入含大于20度的线段俯仰需求。LOS的197个失败中160个首次失败处存在航向或俯仰饱和，旧控制228个失败中73个有该现象。这些是相关描述，终点问题、初始姿态和路径几何可能共同作用，不能据其比例分配独立因果贡献。

初始姿态在本阶段固定，未做新地图姿态干预；旧5A-R首段对齐仅31→33/157，也不足以解释所有失败。球包络确实使N4/margin不可达，但没有姿态相关机体或真实参数对照，尚不能证明多数剩余失败主要来自球过保守。现有水平fillet已修复特定急角例，完整三维曲率/steering参考未验收，所以也不能声称已有成熟处理无法经济地消除几何缺陷。

## 科研判断与下一步建议

本阶段选择 **Inconclusive**。不选择Go-to-innovation：两个控制器共同失败并未排除有限终点适配、小间隙内限速跟踪和包络保守性，缺少通用三维成熟处理对照。不将结果正式定为Refine-controller：换LOS总体只有限改善，并有大量地图/算法退化，不能说多数问题已经通过换控制器解决。不选择Pivot-model：没有证实主要结果由球模型保守性主导。

下一步优先**完善标准控制/执行评测**：在独立解析终点、回折路径和受限姿态场景中验收有限终点衔接、局部进度、角速限幅与到达判据，再进行新的预注册验证。车辆尺寸、姿态相关机体及运动参数应先取得研究者提供的平台依据或标定资料。通过这些前置关卡后，才评估是否需要规划创新；本报告不实现新算法，不继续调当前留出图参数。
