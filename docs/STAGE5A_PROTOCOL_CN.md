# 阶段5A预注册协议

研究者已确认实施方案：RRT-Connect为现有主基线，新增RRT*与Informed-RRT*，评估有限尺寸及无洋流运动学，不开展5B。起点为stage4a提交aac2921，新分支pivot/auv-rrt-stage5a，PR目标stage4a；历史源码、配置、结果和原作者材料冻结。

## 审计结论及依据

原RRT-Connect是双树EXTEND/CONNECT、线性NumPy最近邻、固定步长5及目标偏置.05；全部连接严格验证，但没有选父或重连，不是RRT*。原碰撞核覆盖闭体素连续线段，仅适用零半径。4A普通/地形图具有顶部自由见证，不能直接当近海底作业。4A的时间认证、截止后不倒填及相同shortcut规则沿用思想，新实现显式传入有限尺寸检查器，不修改历史控制器。

基线已实际重跑327 passed in7.24s；compileall、Ruff与92文件格式检查通过。阶段二125、阶段三112、4A402条独立记录与报告核对一致；4A留出A4为29/40、RRT重启40/40，接受Pivot，不把原零半径结果称实体成功。

算法依据：[Karaman/Frazzoli2011](https://arxiv.org/html/1105.1186v1)算法6、[Gammell等2014v3](https://arxiv.org/html/1404.2334v3)算法1/2及椭球公式、[Kuffner/LaValle2000](https://www.kuffner.org/james/papers/kuffner_icra2000.pdf)双树流程。独立自编，不复制第三方实现；arXiv非独占传播许可不等于软件再分发许可，不提交论文或外来源码。参数、精确目标连接、截止与后处理约定明确披露，不承诺有限预算下渐近最优结果。

## 冻结参数与安全定义

完整值见configs/stage5a_protocol.json。新地图单位米、z向上；机长2米、直径.4米圆柱的方向无关包络球半径sqrt(1+.04)≈1.0198米，安全余量.25米。三种规划半径为0、包络半径、包络半径+.25。尺寸及速度/角速度全部是仿真假设，没有已确认车辆型号，不宣称实体规格或6DOF识别。

连续线段到闭体素盒最小欧氏距离判碰撞，障碍接触拒绝；完整包络须处在闭地图内。浮点保守容差1e-9米。空间边界与障碍接触约定分别测试。独立参考方法交叉检查，禁止中心采样距离场非保守插值。安全余量指标为至实际闭体素/地图边界的距离减包络半径；可作3米截断下界，不能冒充未截断精确最小值。

近海床h为高斯高度向上栅格化后的分片常数表面，另加h+6米虚拟顶界，要求整个包络位于作业带内。物理海床碰撞和虚拟任务顶界违反分列。每种尺度重新检查见证；窄孔不满足直径的情况给解析不可达证书，其余没有证明时记unknown，不以规划超时判无解。

运动学为p_dot=v(cosθcosψ,cosθsinψ,sinθ)，ψ_dot=r、θ_dot=q。速度1米/秒，航向/俯仰速率限幅10/5度每秒，|θ|≤20度，dt=.1秒。统一前视3米跟踪、地图固定初始朝向、位置目标容差.75米、无终端姿态要求。常值输入精确积分；相邻姿态之间的曲线用有界弦偏差扩大扫掠球核查，不只验证离散位置。限幅饱和另记，限幅导致的零违例不等于路线可执行。

规划器报告、当前半径严格几何有效、名义机体几何有效、运动学执行成功分别统计。点路径先经名义机体复核，几何拒绝不伪装成控制器失败。原始与共同shortcut输出独立跟踪，同坐标仅保存/模拟一份；固定输出选择规则，不从多个跟踪结果里挑好路径。跟踪时间不倒填规划Anytime曲线。
