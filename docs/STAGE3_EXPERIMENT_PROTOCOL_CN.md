# 阶段三预注册协议

2026-11-11，在任何阶段三搜索结果出现前固定本协议和两个stage3配置文件。阶段二源码、地图、125条数据及指标定义保持不变；阶段三只在新模块中观测，复用冻结函数，不复制控制器。

## 先后顺序与单因素

1. 旧232测试、编译、Ruff检查已通过。新观察层用固定工作量验证路径、候选数、RNG与移除/淘汰顺序一致；S1事件日志单独说明开销。
2. S3的Paper/Safety分别seed0—4，30秒；在完整路径经连续检查并确认端点后，当场记录首次时间、长度与展开数，以及每次严格改善。旧30秒和最终长度不得当首次时间。
3. A：Safety，S1/S2/S3，容量1/3/5/10，宽度5，seed0/1/2，其他参数不动。相同阶段三参照可复用并保留实际run_id。
4. A冻结后做B：宽度3/5/8，容量1，同场景同种子同30秒。不是容量×宽度的笛卡儿积。
5. A*：S1/S2、确定性seed0，节点上限10万→20万→40万→64万，时间均30秒；首次找到有效解即停止向更大节点预算升级。若最后受时间而非节点限制，再固定该节点数单独比较60秒。不覆盖阶段二，不将一次确定性搜索当多个独立样本。
6. 仅当A+B所有S1设置均0/3时做C：容量1宽度5，单独改变径向步长1/3/5，再单独改变半锥角15/30/45；仅S1、seed0/1/2，标diagnostic_only，参照可复用。
7. 若S3最早有效解在5秒内出现，做同seed的stop_on_first_valid对照，唯一变化是停止策略，不冒充原版完整耗时。

本轮不自动扩20seed，不开展完整参数笛卡儿积，也不根据有利种子扩展。正式共同比较预算维持30秒；60秒只属诊断。

## 日志、时间及性能控制

S1 seed0记录插入、容量淘汰、展开与终止open事件，含节点ID/父ID/位置/网格/g/启发分数及空间分箱；上限20000，超出明确计数。全体运行记录聚合候选/淘汰/实际展开。事件只是观察，不把淘汰率当原因或独特路线数。必要反事实必须另标，不混入论文结果。

新主指标是valid_solution_found_by_30s；同时保留normal_completion_by_30s和阶段二budget_valid_success口径。无解证据、预算结束、有incumbent的截止、错误分别记录；空值不能填0。首次时间包含这次独立确认的耗时；插桩开销可能改变截止时展开数，不能与未插桩结果混作速度排名。

profiling仅S3 seed0固定n_max10，分别未观察/观察/cProfile；各类别采用函数self time，不能累加嵌套cumulative time造成超过100%。若profiling在截止前未完成相同工作量，明确报告不可直接对比。

每次独立子进程记录Windows PeakWorkingSetSize（进程生存期峰值，含加载），不把持久worker累计峰值当本次搜索峰值；另记初始RSS。该内存口径不宣称仅搜索增量。

## 开发集、留出集与对照

S1/S2/S3为开发集。H1/H2在扫描前固定新几何、尺寸和起终点，验证见证，但不用于选参、不向规划器传见证。A/B后，按开发集9个预定任务中valid_by_budget数最多选择单一因素设置；未严格优于参照就保留参照，平局取较小容量、宽度离5较近。禁止将最佳容量和最佳宽度组合。

冻结选择后，H1/H2上比较Safety参照、所选设置（不同才另跑）、RRT-Connect，seed0/1/2。留出结果不再调参。开发集也保留同种子新RRT对照。原始长度、共同shortcut长度及首次时间分别列示，避免用RRT原始锯齿路径夸大G-Sunlight优势。

仅零半径静态几何折线。最终报告区分事实/推断/局限，逐项回答S1、S3、A*、可靠优势和是否继续主线。只建以stage2为base的stage3 PR，不合并，不进入新算法开发。
