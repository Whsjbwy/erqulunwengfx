## 2. 模型语义必须保留

冻结植物是五状态`(x,y,z,yaw,pitch)`简化运动学：水体相对速度1m/s；yaw/pitch角速率限制分别±10°/s、±5°/s；pitch科学边界±20°，既有1e-12rad容差只是数值接口约定；z向上、步长0.1s。外接球半径约1.019804m，额外必需余量0.25m；到达为0.75m位置目标球，不要求终端姿态。它没有质量、惯性、水动力、推进器动力学或完整滚转状态，不能称为真实6DOF AUV。

原无流闭式积分和转向引起的弦偏差证明不能直接搬到`p_dot=v*b+w(p,t)`。任务书中的加速度上界需要有效域内可靠的W/Lx/Lt、区间连续性及端点积分不确定性共同成立。有限测量本身不保证未知区域梯度有界。以上只是审查数学前提，**本轮未实现或验收有流积分器/证书**，因此不生成`STAGE8A_MODEL_AND_CERTIFICATE_CN.md`来冒充门槛B成果。

## 3. 文献查新实际结果

完整字段见[文献矩阵](STAGE8A_LITERATURE_CN.md)、`results/stage8a/literature_sources.json`和`tables/literature.csv`，访问受限事实见`access_log.json`。每项区分正式DOI、预印本DOI、实际读到的方法、代码许可与未核实部分。10项中8项取得本轮可读方法全文或作者方法全文；L1本轮仅重获摘要，保留7B-0全文记录；L5始终未获全文。作者版本不冒充正式版逐式核对。

最接近的三个方法为L8、L3、L7：

- [Chou等，CDC2021扩展版](https://arxiv.org/html/2104.08695v2)已把局部Lipschitz误差界、跟踪管、可信状态/控制域和采样规划相连。把同一机制改称“局部流界安全管”不足以构成新贡献。其稳定性和概率验证前提也不能省略。
- [Karthik等，Ocean Engineering2026作者版](https://arxiv.org/html/2604.05310v1)已结合局部障碍点云、三维不变区域和反馈规划；其可控速度及低层实现假设不同于本项目固定正水速。不能把障碍感知解释为局部流场感知，也未证明两者机制完全等价。
- [Jeong等，L4DC2024](https://proceedings.mlr.press/v242/jeong24a.html)已研究参数化误差界和环境余量相关的速度/保守性调整。其感知范围与学习近似前提必须保留，不能把“减少全局保守性”本身当作空白。

此外，FaSTrack已覆盖有界扰动跟踪保证；2023安全USV引导已使用流扰动及导数有界假设。L2虽题名含robust，正文当前模型明确无洋流且为二维，不是三维受流强基线。L1已有流向代价、走廊和时空优化；L5摘要已有时变流、安全和速度可行，关键公式未知。未找到官方代码、访问403、没有在摘要出现某术语，均不能用于证明原创性。

## 4. 唯一候选及门槛决定

仅保留一个**待证伪问题**：有限感知且具有可验证的局部流值/空间梯度/时间变化界时，固定正向水速与yaw/pitch限制是否产生未被最近邻覆盖的持续安全可达性判据，并较全域最坏界减少误拒？没有给它命名算法。

目前只能确认通用机制已有覆盖，尚不能证明这一具体联合条件完全等价，也不能证明存在实质差异。L5关键全文不足，L1本轮全文不可重获，局部界如何获得及可信域前提也未解决。因此门槛A为NEED_MORE_EVIDENCE，门槛B为NOT_ENTERED。任务书明确要求此时停止模型开发；用户批准的执行上限不是必须凑满的实验数量。
