# 阶段5A-E预注册协议

2026-11-13研究者确认超过3文件方案；基线PR #6/9dbd5ec，独立分支audit/auv-stage5ae-evaluation，PR目标audit/auv-stage5ar-execution。历史PR #1—#6全部冻结。本协议在新增实验前提交；不把测试数、旧157条路径与新规划试验混计。

E0先重跑原450项测试/静态检查，固定12条旧路径复现，独立检查直线、缓曲线、受控俯仰和几何负例。读取旧1099条件逐步记录，为每个失败添加首次区间、最近段、进度、前视目标、姿态/饱和和1米局部参考邻域的保守间隙。全局最近点与历史最大进度均保留；>0.5米步间映射变化仅作描述标记，不自动认定软件错误。合成回折例用于展示映射不连续的可能性。

独立控制参考为Breivik/Fossen (2005) 的三维引导方程(37)(38)(46)(54)(56)(57)。路径切向坐标下误差(s,e,h)，相对方位角−atan2(e,Δ)，相对仰角−atan2(h,Δ)，合成惯性系期望速度方向；虚拟路径点按U cosχr cosυr+γs推进，γ=1。z向上坐标与原文NED符号转换明确实现，路径进度采用0.1秒Euler并限制在有限路径范围。原位置精确积分、角度比例内环及全部限幅不变。分段折线与限幅不满足论文理想光滑/瞬时执行假设，不宣称继承其稳定性证明。其虚拟进度/切向误差引导不同于旧全路径最近点+截断前视，不是旧控制器改名。

来源：[作者公开原文](https://www.fossen.biz/publications/2005%20Breivik%20and%20Fossen%20CDC.pdf)，DOI10.1109/CDC.2005.1582226。两个出版社入口访问失败后采用作者公开原始论文，不依赖无法读取的公式；不复制或提交论文/外来源码。

E1固定两候选Δ=2、4米，不直接将旧1.5米选为默认。12条先验样本按每图“历史最早失败＋最早成功；无成功则最晚失败”，并列job_id。正例/资源门槛通过后，完整157条selected开发路径一次性比较；先地图等权严格完成、再名义完成、再全路径RMS误差、最终小Δ决胜。所有候选和退化案例保留。初始航向指终点、俯仰0、速度1、角速/俯仰/终点/误差/时间/球包络及连续安全与5A一致。

E2在同157任务的同源raw_best上，比较raw/一次固定greedy shortcut×旧控制/选定LOS。成熟曲率参考采用水平切线圆弧fillet：转角φ，切点距离R tan(φ/2)，R=v/ωmax；几何基础参照Beard/McLain的标准fillet路径管理，[官方ROSflight说明](https://docs.rosflight.org/git-main/user-guide/rosplane/navigation/path-manager/)。只在水平面适用，短段、反向角、非水平输入明确拒绝；直线与圆弧由解析原语和弦偏差界连续认证。三维推广不冒充已有合格实现，正式三维矩阵预先限定raw/shortcut。仍逐条报告曲率参考的适用/拒绝，不能删除不支持输入。

E1/E2完成后提交开发选择和资源门槛，随后才生成新地图并开始E3。新地图配置预先列出12图，三类各4；椭球链、双错位隔墙、波纹/坡道阶梯地形均不同于5A配方，同时改变尺度和端点。地图只按配置生成一次，不按搜索/控制结果重采样。见证用于认证指定球包络的几何可达性，不替代规划器输出；E_N4的2.5米孔径对margin包络是预定负例，对名义球需验证见证。未知可达性单列。
