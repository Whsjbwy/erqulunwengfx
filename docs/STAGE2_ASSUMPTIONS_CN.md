# 阶段二独立论文重建：依据、假设与实现边界

本文针对 `stage2-paper-v1` 与 `stage2-safety-v1`。它们是依据论文算法1—5和公式(1)—(6)独立编写的参考实现，不导入或再分发作者源码，不代表获得作者未公开实现。阶段一原版记录保留原样，不将其改名为本阶段的独立算法。

## 1. 方法身份与共享部分

| 方法 | 本仓库身份 | 搜索控制与安全边界 |
| --- | --- | --- |
| Paper-Reimplementation | `paper_reimplementation` / `stage2-paper-v1` | 遵循论文总体结构；显式补足未定义的选择策略；算法5入图前不暗加父边过滤；最终原始路径独立严格检查，失败保留路径证据并标记 `error/invalid_solution` |
| Safety-Reference | `safety_reference` / `stage2-safety-v1` | 同一自编论文控制器显式开启父边检查及完整目标路径检查；不是阶段一作者代码hook，不使用A*或其他算法兜底 |

两者共享自编旋转、射线、容量网格、路径回溯、结果和预算类型，避免维护两份漂移的相同控制流程。差异通过入口的明确 `safety_guards` 选择记录。两者均保留原始路径作为主要结果，不在内部给某个方法独享后处理。共同后处理应由实验层另行记录；安全参考提供只验证与回退的辅助函数，不自行生成平滑路径。

## 2. 明确采用的论文结构

- `Openset` 按实际累计长度 `g` 排列，代价并列时按节点ID稳定排序。选取节点后，移除其当前网格成员身份，保留历史最短长度。
- 当前太阳节点先检查到目标的整条连接；可直连则保存完整父链路径并继续搜索，不因首次路径出现而提前停止。
- 容量网格历史值初始为无穷大。严格更短的新点插首位并更新历史；其余点插列表索引1；超过 `cons` 时删除末点及对应的 `Openset` 项。
- 容量淘汰只移除待扩展身份，不删除已经记录的图节点和父链。起点初始化到容量网格，历史长度为0；目标作为专门的终端，不作为普通待扩展候选。
- `g(child)=g(parent)+欧氏边长`。完整路径成本为 `g(sun)+||goal-sun||`；不以启发式分数代替实际几何长度。目标连接保存各自路径，不覆盖共享终点的父链。
- 论文计数器从0开始，循环使用 `i≤n_max`；直连分支 `continue` 不递增 `i`；无切点的非直连分支仍递增。另记实际太阳处理数，外部迭代资源上限与该计数器分开。
- 公式(1)—(3)按论文Y旋转符号及 `Z→Y→X→Y` 顺序实现，内部角单位为弧度，公开参数角单位为度。
- 算法3遍历 `φ=k·φ_step<360°`，`θ₁=j·θ_step≤半锥角`。半锥角属于步长格点时保留上限；不属于时不额外插入离格点角度。`φ=0`平面参与射线求值，但不生成切点，符合算法3的条件。
- 相邻射线自由长度差必须严格大于阈值；在较长自由射线上取“较短自由长度+前进距离”的点。每个方位平面重置前一条射线，不额外补首尾角缝比较。
- 平面算法2提供独立XY接口，固定输入z，使用完整角圆周，不把三维锥形采样退化模式冒充二维算法的实现。

## 4. 参数、预算与计数口径

公开 `plan` 接口接收平坦参数字典；未知参数直接返回 `invalid_input`，不静默忽略。每次结果记录完整展开后的参数、seed、预算、碰撞策略和选择规则。

| 参数 | 默认值 | 依据 |
| --- | --- | --- |
| `theta_step_degrees` | 5 | 论文三维几何场景 |
| `phi_step_degrees` | 10 | 同上 |
| `half_cone_degrees` | 30 | 同上；采用论文包含格点上限的循环 |
| `distance_step` | 5 | 论文三维几何场景径向步长，不采用源码内射线固定1的行为 |
| `length_threshold` | 15 | 论文三维几何场景；严格大于 |
| `forward_distance` | 3 | 同上 |
| `grid_side_length` | 5 | 同上；单位为地图坐标单位 |
| `grid_capacity` | 1 | 同上 |
| `n_max` | 100 | 所提供源码补足 |
| `epsilon`, `alpha` | .8, .5 | 所提供源码补足，按上表公开解释使用 |

单次内部截止时间从入口开始，包括本方法的数据结构初始化与必要的输入/内部检查；内层射线遍历、候选逐项入图和主循环均检查截止时间。图节点预算包括起点、特殊目标和已经生成的永久图节点，即使节点被容量淘汰也不归还该预算。`PlanningLimits.max_iterations` 限制实际太阳处理数，不替代论文计数器。

预算耗尽使用 `timeout` 或 `budget_exhausted`，与 `open_exhausted`、`paper_iteration_limit` 区分。已有候选解时保留原始路径与 `reported_success`，但不把预算状态改写为正常完成。没有路径时用空值，不填写零长度。`reported_success` 只表示实际形成过完整路径；终验结果另列，无效路径保留证据且不能计作严格有效成功。

计数器含义：

- `expanded_nodes`：实际取出的太阳数，包括可直连目标的节点。
- `sampled_nodes`：实际查询的射线数，结果事件明确标记单位 `rays`，不是图顶点总数。
- `generated_candidates`：采样器实际产生的切点数。
- `valid_candidates`：本方法允许入图的候选数；Paper仅表示有限坐标被算法接纳，不能当成严格安全认证；Safety还须通过父边检查。
- `collision_filtered`：Safety拒绝的父边或完整目标路径数；不把射线正常遇到障碍算成候选被过滤。
- `capacity_evicted`：容量超限引发的末项移除次数，包含新点自身被移除。
- `no_candidate_expansions`：该非直连扩展没有产生任何原始切点的次数；Safety有切点但全部拒绝可由生成数和接纳数进一步判断。
- `collision_checks`：连续几何查询次数，包括整射线supercover、校正用前缀和必要整路径检查；不声称它等于作者论文每次 `CollisionFree`调用的实现成本。
- `final_open_nodes`：结束时尚未扩展的候选数；事件另记永久图顶点数、完整路径集大小和论文计数器。

## 5. 射线等价优化与验证要求

逐径向步长重新检查从太阳出发的整个前缀，会反复遍历相同体素。本实现先对整条域内射线做一次严格supercover，找最早占用体素，再用闭AABB的slab进入距离恢复真实碰撞距离。不能直接用supercover返回的区间中点充当碰撞进入距离。根据首次障碍/域边界推导最后合法的离散步长，随后检查相邻离散前缀，校正接触及浮点边界情况。

该优化保持论文的离散径向采样口径，不跳过细障碍，也不以固定稠密点采样替代连续碰撞。单元测试将其与小地图上逐步完整前缀的朴素参考比较，覆盖随机占用、非单位spacing、非零origin、闭面接触、地图边界和非法射线起点。朴素参考只用于测试，不用于批量实验。

实现优化不构成论文复杂度公式的实测证明。公式(4)—(6)分析固定参数条件下的碰撞函数调用数，不能自动说明本实现的实际总运行时间严格线性。

## 6. 质量控制边界

合成流程测试采用可注入采样器，只用于隔离验证“先直连、保留多个路径、计数、淘汰、预算、父链”等控制逻辑；真实采样几何另外测试。初次测试设计中一条宣称可绕行的路线实际接触墙角，严格检测正确拒绝；该几何已保留为明确的应拒绝反例，正常流程夹具改用经过验证的无碰撞路线。这不涉及改变实验地图或调节方法参数。

本文件说明规则和测试范围，不预填多地图实验成功率或时间。实际场景、固定配置、运行命令及统计必须以阶段二真实输出为准。
