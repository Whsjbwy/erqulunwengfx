# 阶段8A科研准入决定

**项目决定：BLOCKED。任务书门槛A：NEED_MORE_EVIDENCE；门槛B：NOT_ENTERED。不推荐进入原创算法原型。**

这两个标签描述不同层次：BLOCKED回答用户要求的GO/PIVOT/BLOCKED项目状态；NEED_MORE_EVIDENCE保留任务书要求的精确科研原因。不是算法失败或模型不一致，也不是证明整个复杂洋流选题没有研究价值。

1. **已有研究覆盖什么？** L8已覆盖局部Lipschitz误差界、安全跟踪管、可信域和采样规划协同；L3已覆盖局部障碍感知与三维不变安全规划控制；L7已覆盖环境相关的参数化误差界/速度调整。FaSTrack和受流USV安全引导进一步说明通用扰动管、流估计及导数有界不是空白。单纯“加入洋流”“适配AUV”“减小保守性”不构成新机制。
2. **还保留什么问题？** 只有一个待查新问题：可验证的有限感知流场界与固定正水速/yaw/pitch限制是否联合产生尚未覆盖的持续安全可达性判据。它没有通过创新性准入，不能先命名新算法。
3. **为何不能GO？** 关键L5只有摘要，L1本轮未重获全文；具体联合机制既未证实不同，也未证实完全等价。局部观测如何获得有效域内的可靠梯度/时变界也未解决。任务书不允许用这些未知支持新颖性。
4. **模型正确性是否已经证明？** 没有。历史无流模型证据仍有效；有流积分、数值误差传播、连续碰撞界及有效域验收均未实施。六类演示全部未运行，没有新成功率和轨迹图。
5. **Windows能否做下一轮公平实验？** 轻量解析验证在资源上合理，已有官方OMPL无流基础可复用；受流同模型适配和最近邻强基线尚未建立。因此只能说资源可承担，不能说基线已准备完成。

若研究者批准继续补证据，应优先取得L5合法全文、复核L1方法，逐项检查流信息、速度/转向/俯仰控制集合、鲁棒保证和有效域；不增加模块或参数扫描。若确认等价，转向；若不能给出具体可证伪区别，继续停止。即使将来门槛A通过，也必须先做门槛B，不能直接进入规划实验。

未来可能的否定标准：最近邻在相同信息与控制条件下已有同一判据；局部界不能可靠获得；安全依赖离开感知有效域；减少误拒只是放松物理或安全阈值；去除声称机制后结果不变。任何一种成立均不能继续以当前机制申报原创。

将来获批的公平对照必须保持同一五状态模型、流场信息、限幅、球包络、0.25m余量、0.75m目标球和时间预算；至少有官方Control RRT/SST、全域保守安全基线及核实后的最近邻方法。局部流场已知的方案不能和只知全域界的方案直接解释为算法优势。冻结后才使用至少两种独立未见流条件；本轮没有生成这些条件或运行试验。
