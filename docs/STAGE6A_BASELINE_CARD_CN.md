结论：当前证据支持研究“有限时间内寻找满足运动约束且能由统一跟踪器执行的路径”，不支持把车辆模型称为真实六自由度动力学。该卡只解释冻结成果，没有重新运行或修改历史实验。

## 五状态简化运动学

状态记为`s=(x,y,z,ψ,θ)`，`z`向上，航向`ψ`按周期角处理，俯仰`θ`向上为正。输入为`u=(r,qθ)`，其中`r=ψ̇`、`qθ=θ̇`均是Euler角导数；不是完整刚体的体轴角速度。冻结模型为：

```text
x_dot = v cos(theta) cos(psi)
y_dot = v cos(theta) sin(psi)
z_dot = v sin(theta)
psi_dot = r
theta_dot = q_theta
```

| 参数 | 冻结值与含义 |
| --- | --- |
| 名义前向速度 | 1 m/s，6A不改速；没有加速度或制动状态 |
| 航向角速度 | `|r| ≤ 10°/s` |
| 俯仰角速度 | `|qθ| ≤ 5°/s` |
| 俯仰角 | `|θ| ≤ 20°` |
| 时间步长 | 0.1 s，常值输入使用历史解析积分 |
| 车辆外形假设 | 长2 m、直径0.4 m圆柱的外接球，半径`√1.04 ≈ 1.0198039 m` |
| 额外安全距离 | 0.25 m；历史有body/margin两种模式，6A正例统一采用球半径加0.25 m |
| 到达判据 | 进入目标位置0.75 m球；没有终端姿态约束 |
| 跟踪误差阈值 | 3 m，是失败阈值，不能当作可用避障净距 |

尺寸、限幅均为未辨识仿真假设，没有将其认定为某型真实AUV参数。模型省略滚转、侧滑、升沉惯性、角加速度、推进器、舵机、质量/惯量、阻尼、水动力耦合、浮力配平、传感器误差与洋流。不能从本项目成功率推断海试成功率。`v>0`时进入目标球是一次到达事件，不是悬停、停车或终端稳定；需要停车的安全策略不能直接搬入。

空间曲率在恒正速时为：

```text
kappa = sqrt((r cos(theta))^2 + q_theta^2) / v
```

单独给出最小转弯半径或总曲率上界，不等价于上述不对称矩形率约束。例如`r=0,qθ=8°/s`可满足`κ≤(10°/s)/v`却违反俯仰率；合法的`r=10,qθ=5,θ=0`反而超过该标量界。这是模型兼容性检查，不是创新结果。水平恒航向率半径约5.7296 m，不能把此数当作全部三维转弯的唯一半径。

连续安全认证复用历史体素盒几何、外接球和区间曲线弦偏差包络`v hypot(r,qθ) Δt²/8`。认证对象是整个运动区间，而非显示抽样点。该包络保守；拒绝既可能是真实外接球相交，也可能因保守包络不能认证。外接球相交不等于真实圆柱必然碰撞。6A不更换形状模型来改善结果。

## 历史证据及其可解释范围

| 阶段 | 实际记录 | 已支持的判断 | 不能据此声称 |
| --- | --- | --- | --- |
| 5A | 450次，380条几何通过；包括不同阶段/半径与60个已知负例 | 几何规划与受限执行存在差距 | 将380/450直接当作统一条件的性能 |
| 5A-R | 157条诊断样本；单因素速度/初向/前视/处理对照 | 对控制参数和处理敏感，存在恢复也存在退化 | 某一前视距离可解决所有图，或唯一因果机制已识别 |
| 5A-E | 360次规划、306条几何路径、1224次真实执行 | 成熟LOS与路径处理的同源对照，识别末端缺口 | E图在6A仍是独立盲测 |
| 5A-F旧路径 | 306条原路径、612个新增修正条件 | 54个旧末端问题中3恢复、45仍误差、6转安全拒绝 | 只计恢复、忽略安全退化 |
| 5A-F新图 | 216次规划、194条解、1164实际执行、1296登记条件 | 固定LOS的388条件中312失败，308次首次失效在终端切换之前 | 末端修复已经解决中途运动学/安全问题 |

5A-F在207个已知**几何**可达任务中得到194条解，另13个搜索无解；9个任务有孔径不可达证据。几何可达不等于当前初始姿态和有限角速度下可达，搜索无解也不是不可达证明。历史独立审计重新认证434493个区间，3492个RK4抽查最大偏差`1.7053e-13 m`，支持实现一致性，不是水动力真实性证明。

按每个处理/跟踪器分组，`K=216,G=194,E=194`。例如legacy原始路径`S=74`，条件成功率`74/194=38.14%`，完整任务成功率`74/216=34.26%`；修正LOS快捷路径`S=59`，分别30.41%与27.31%。原始修正LOS为17/194；末端修正在F图上没有新增成功。不能将同一路径的多个控制条件当作独立地图重复。

## 指标与术语固定

| 术语 | 定义 |
| --- | --- |
| 位置空间几何成功 | `G/K`，通过完整几何认证并满足端点的规划任务比例 |
| 条件执行成功 | `S/E`，仅在实际取得合格参考并执行的条件中统计严格成功；同时报告`E`及未执行原因 |
| 完整任务成功 | `S/K`，同一固定处理/控制流程的所有登记规划任务作分母，无解仍占分母 |
| 运动可行轨迹 | 给定控制按冻结微分方程传播、输入/状态限幅及全区间安全均合格，并进入目标球 |
| 统一跟踪成功 | 将参考交给同一冻结控制器后实际严格成功，另行统计；不能用开环传播成功代替 |
| 五状态简化运动学 | 状态维数与假设的描述；不用“五自由度动力学”“六自由度已复现”等说法 |

6A之后所有H5、E、F地图及其结果都属于开发/诊断资料。禁止再次标为独立验证集。
