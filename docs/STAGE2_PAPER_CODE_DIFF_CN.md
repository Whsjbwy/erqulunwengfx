# 阶段二论文、作者示例与安全参考差异

依据研究者提供的14页论文、所提供作者ZIP和本仓库独立实现核对。论文页码和Algorithm行号对应该PDF；`main`、`utils`行号对应ZIP原件，不是对未来上游代码的保证。本文不复制作者代码，也不把未公开细节称为已精确恢复。旧版本静态审计仍保留在[阶段一审计](PAPER_CODE_AUDIT_CN.md)。

论文：[Deng等，2026，DOI:10.1002/rob.70356](https://doi.org/10.1002/rob.70356)。来源仓库：[breaker123344/LIU3Dsunlight](https://github.com/breaker123344/LIU3Dsunlight)。所检查材料未见明确 `LICENSE`，作者原件仅在本地使用。

## 1. 三版本逐项核对

## 2. 保留证据与实验解释

作者原版的“正常返回”不等于严格有效。阶段二分别保存原始路径、作者原生处理后路径、共同严格shortcut结果及各自验证；只有原始路径严格有效，才允许进入共同后处理。Paper若形成了无效路径，保留坐标并标记错误，不能静默移除或修好再覆盖原始记录。Safety不以兜底算法填成功率。

Paper/Safety在默认前进距离小于长度差阈值且射线前缀已经连续严格检查的条件下，父边保护可能不会改变路径；应如实报告相同结果，不能为制造差异改变实现或地图。三版本之间同时改变控制结构、径向分辨率、几何规则和容量细节，不构成单因素因果消融。

S0—S4均为独立自编、提前固定的确定性场景配方，不是论文原始地图；`map_seed`只是配方标识，没有随机障碍抽样。S3的正地图z和显示偏移−80也不等于论文海床重建。五个规划seed的重复不代表随机地图总体实验，A*的重复主要用于计时。

`reported_success`、原始路径 `strict_valid`、正常完成且搜索在预算内的 `budget_valid_success`分开；超时或异常缺观测时保留未知。射线数、图节点数、随机样本数不混作统一采样节点排名；容量淘汰、候选过滤和空扩展是观测事件，不自动解释失败因果。详细规则见[版本指南](STAGE2_VERSION_GUIDE_CN.md)。

## 3. 仍不能声称完整严格复现的事项

1. `ChooseSun`的精确公式、概率、并列规则，初始化网格细节、数值容差及全部停止预算没有完整公开；本项目选择可执行解释并记录，不将其冒充原作者唯一解释。
2. 本机只拥有所提供单张地图和示例材料，缺少论文全部场景、对比算法调参、随机种子及实体条件。表1—3、120秒RRT收敛和二维水池实验不能由本阶段合成场景替代。
3. 零半径折线通过闭体素检测不代表带实体半径、动力学和控制约束的AUV可执行；当前工作是可信性核查，不是新的科研创新，也不保证论文发表结论。

实际完成的运行、结果、测试及未完成项以[阶段二报告](STAGE2_REPORT_CN.md)为准，不在差异文档中预设成功率。
