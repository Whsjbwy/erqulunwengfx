# 阶段6A候选假设与唯一主方向

保留两个候选供审核，主方向仅选择H1；H2不作为原创开发目标。本文件为AI辅助形成的可反驳研究设计，创新判断与后续授权由研究者审核。没有命名新算法、实现原创模块或报告未运行的性能。

## H1：净距与姿态需求共同决定传播时长是否有额外价值

**问题。** 恒正速AUV不能原地转向。短传播可能浪费搜索，长传播可能越过窄可行通道；位置空间净距与改变航向/俯仰所需时间可能共同影响有效扩展。假设在不改变控制分布、输入限幅、碰撞oracle、树选点/剪枝和总预算时，基于两者的**条件化传播时长分布**，比成熟SST的均匀时长分布更容易在有限时间内找到严格可行轨迹，而且改进能在统一冻结跟踪器下保留。

研究对象严格限于模型卡中的五状态，不宣称解决水动力、未知模型鲁棒控制或六自由度可达性。局部姿态需求可用指向同一采样目标的航向/俯仰差表示。定义：

```text
tau_att = max(abs(wrap(psi_target-psi))/r_max,
              abs(theta_target-theta)/q_max)
tau_gap = c_cert / v
```

`c_cert`为同一有效半径下的局部认证净距下界。`tau_att`只表示角速度下界，不能证明能到达目标；`tau_gap`只给出以当前点净距构造的保守局部尺度，不能证明通道可达或不可达。二者是分布的输入特征，不能用于未经证明的硬剪枝。

机制若继续研究，应保持至少`epsilon>0`的原始全支撑时长/控制采样，避免按特征把绕行、长转弯或窄通道永久排除。传播时长为0.1秒整数倍；具体范围、混合权重、状态距离权重仅能在旧图开发集冻结，当前不虚填“最优参数”。不能直接继承SST/RDG理论；偏置、离散化和证书保守性都需重新审查相关假设。

**与文献的差异边界。** SST和RDG已有随机时长，VK-RRT*已有自适应扩展及速度/曲率/安全距离耦合，KRAFT已有规划控制协调。因此潜在贡献只能落在“同模型下明确的联合条件关系及其可归因的有限预算效果”，不是可变步长、双率、净距或前向传播本身。若发现已有等价条件化策略，应Pivot；不能把应用到AUV当成充分理论创新。[逐项近邻审查](STAGE6A_NOVELTY_GAP_CN.md)

**可证伪预测。** 开发与全新独立地图上，联合机制相对同核SST和同预算control RRT，提高严格运动可行解发现率及统一跟踪完整任务成功率；收益应主要出现在急转/高低转换且净距受限层，而不是仅来自无障碍直线。失败的已知运动可行正例不能从分母删掉。

**必要消融。** 只用净距、只用姿态、打乱两特征的配对关系，各保留相同原始采样支撑、传播范围、候选控制数和计时；与原始SST形成单因素链。若只增加候选数、给予更多碰撞调用或更宽安全标准即可获得相同改善，则不能归因于联合机制。

**停止条件。** 同核成熟基线经公平开发就消除主要差距；独立结果没有预注册的实际改善；收益只存在于原生开环而不在统一跟踪；变更球半径或到达阈值才有效；最邻近文献已覆盖；或采样开销使总时间变差。上述任一项触发复核，不能通过继续调独立集挽救。

## H2：几何路径前置转角/俯仰限制并平滑

假设为几何RRT在选父/重连中限制角度，再通过3D曲线或B样条消除拐角，以提高执行成功。该方案工程上有意义，但Yao2026、Pan2025、Feng2024及其他路径处理工作已直接研究核心组成；离散角度不保证连续率，平滑后仍须重新认证。当前差异不足，**否决其作为原创主方向**。可保留为后续匹配预算的工程参考，不能换名包装成创新。

## 选择与成本

选择H1作为**唯一待审核研究问题**，理由是与历史中途失效机制直接相关、可在既有ODE/安全oracle上单因素检验，CPU计算与数据存储成本可控；并非已经证实新颖或有效。当前先补成熟原生基线和近邻方法证据，最终状态`Need-Baseline-Evidence`。本阶段结束后停止，不自行进入H1原型实现。
